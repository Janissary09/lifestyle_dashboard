# Lifestyle & Heart Dashboard

This project is an interactive data visualization dashboard developed for the FHGR course **Datenvisualisierung**.

The dashboard visualizes lifestyle-related and heart-related variables and allows an exploratory analysis of the dataset through interactive visual elements.

---

## 📊 Project Description

The main objective of this project is to visually explore and present relationships between different lifestyle factors and heart-related metrics.

The focus lies on:
- clear and structured data visualization
- interactive exploration of variables
- visual comparison of distributions and relationships

The dashboard supports intuitive understanding of patterns and tendencies within the data.

---

## 🔍 What the Dashboard Shows

The dashboard provides:
- interactive selection and filtering of variables
- visualization of data distributions
- comparison of selected lifestyle and heart-related indicators
- exploration of relationships between different variables

All insights are derived through **visual analysis**.

---

## 🧩 Key Features

- Interactive web-based dashboard
- Dynamic visualizations using Plotly
- Structured layout for exploratory data analysis
- Clear separation of variable groups

## 🛠️ Requirements

To run this project, the following software and libraries are required:

- Python 3.9 or higher
- Dash
- Pandas
- Plotly
